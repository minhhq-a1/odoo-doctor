# Releasing odoo-doctor

1. Bump the version in `pyproject.toml`, `src/odoo_doctor/__init__.py` (read by the JSON report), `README.md` (including the `minhhq-a1/odoo-doctor@vX.Y.Z` action example), `CLAUDE.md` (the `Current version` line) and `AGENTS.md`, plus both `version` fields of `editors/vscode/package.json` and `package-lock.json`. `tests/test_version.py` enforces pyproject == `__version__` and that `CHANGELOG.md` has a `## [X.Y.Z]` entry; `tests/test_vscode_extension.py` enforces the extension version; the README/CLAUDE/AGENTS bumps are not tested.
2. Update `CHANGELOG.md`; regenerate `docs/rules.md` if rules changed.
3. Merge the bump PR to `main`. That is the release: `.github/workflows/release.yml` runs on every push to `main` that touches `pyproject.toml`; when `vX.Y.Z` has no tag yet it checks the tag against the package version (`scripts/check_release_version.py`) and the CHANGELOG entry (`scripts/changelog_notes.py`), pushes the tag and starts `publish.yml` (a Release created with `GITHUB_TOKEN` would not trigger it). `publish.yml` runs the tests and ruff, smoke-tests the built wheel, publishes to PyPI via Trusted Publishing, then creates the GitHub Release (body = the CHANGELOG section, `.vsix` attached) and publishes the extension to the Marketplace. Any other `pyproject.toml` change is a no-op because the version is already tagged. Do not tag by hand. A version bumped earlier is released from Actions > Release > Run workflow (branch `main`); a failed publish is re-run from Actions > Publish to PyPI > Run workflow with the tag as the ref. Prerelease tags such as `v0.11.0rc1` are rejected by the tag check: only plain `vX.Y.Z` versions are released.
4. VS Code Marketplace: `publish.yml` publishes the `.vsix` with the repository secret `VSCE_PAT` (publisher `MinhHong`, scope Marketplace > Manage). Without the secret the job only warns and the `.vsix` on the GitHub Release is uploaded by hand at https://marketplace.visualstudio.com/manage/publishers/MinhHong. Never put the token in the repo or in chat.
